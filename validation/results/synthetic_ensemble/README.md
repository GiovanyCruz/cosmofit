# Synthetic recovery: 20 independent realizations

These files contain the numerical summaries of the synthetic-recovery
experiment reported in Section VI.B of the manuscript.

- realizations.json: posterior means, standard deviations, credible
  intervals, pulls, coverage indicators, and convergence diagnostics
  for each realization.
- aggregate.json: ensemble statistics across the realizations.

All 20 runs completed successfully and were flagged as converged.
No realizations were excluded from the aggregate statistics.

The generation and analysis scripts are in validation/matched_cobaya/.
